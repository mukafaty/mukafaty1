# خطة صفحة تقارير الأداء

## النطاق
- إنشاء صفحة جديدة فقط في `/dashboard/perf-reports` وإضافة رابطها بعد «عملائي» في القائمة الجانبية.
- استخدام الصورة المرفقة كمرجع بصري دون تضمينها في الصفحة.
- تنفيذ المرحلة الأولى ببيانات تجريبية مترابطة، مع تجهيز البنية للحسابات والفلاتر والتصدير في المراحل التالية.

## التنفيذ
1. إنشاء مصدر بيانات مستقل للمنصات والبرامج، يشمل المفاتيح والشعارات والقيم المترابطة وحساب المجاميع.
2. إنشاء الصفحة باتجاه RTL وبنفس تخطيط مكافآتي: العنوان والوصف وشارة «بيانات توضيحية»، ثم الفلاتر بسطرين على الكمبيوتر وتخطيط متدرج على الجوال.
3. تجهيز اختيار الفترة المخصصة لتفعيل حقلي التاريخ، وحالتي زر مسح الفلاتر، مع إبقاء زر PDF بصريًا فقط.
4. إضافة خمس بطاقات مؤشرات، وجدول أداء المنصات مع الإجمالي، ورسم أعمدة تفاعلي بتبويبات المؤشرات، وجدول أداء البرامج مع ترقيم 5/10/15.
5. إضافة مكوّن شرح موحد يدعم الفأرة والضغط واللمس ولوحة المفاتيح، ويغلق بالنقر خارجًا أو Escape مع ضبط موضعه داخل الشاشة.
6. تجهيز حالات التحميل وعدم النتائج وفشل التحميل داخل الصفحة دون ربط قاعدة بيانات.
7. إضافة بيانات الرأس الخاصة بالصفحة، ثم التحقق بصريًا على الكمبيوتر والجوال، بما في ذلك التمرير الأفقي للجداول والرسم.

## التفاصيل التقنية
- إعادة استخدام تخطيط الداشبورد الحالي ومكوّنات الأزرار والحقول وأسلوب الجداول والترقيم.
- استخدام مكوّن الرسم البياني المثبت حاليًا، مع تعريف ألوان المنصات والتدرجات عبر توكينات التصميم العامة عند الحاجة.
- عدم تعديل أي صفحة أخرى أو منطق مشاركة أو قاعدة بيانات.
